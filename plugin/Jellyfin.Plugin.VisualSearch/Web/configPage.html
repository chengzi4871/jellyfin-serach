Visual Search

视频语义搜索

使用云端多模态 Embedding 和 Qdrant，从视频标题、Trickplay 画面以及无 Trickplay 视频的 Primary 封面中查找语义相近内容。普通 Jellyfin 搜索保持不变，语义搜索通过主界面右下角入口打开。

连接与模型

所有云端模型信息在此配置，插件不读取环境变量，也不使用 Worker。

Docker 中的 127.0.0.1 指向 Jellyfin 容器自身。Embedding 服务在另一台电脑时填写局域网地址；Qdrant 同理。保存后会自动检查连接。

Embedding 与取帧

批量大小影响远端吞吐；截图上限影响云端成本和索引时间。

系统按视频时长决定基础采样点。长视频可使用最多 24 个本地场景探针，最终发送到云端的帧数仍受上限控制。没有可用 Trickplay 帧时，插件会读取 Jellyfin 的本地 Primary 封面；封面命中不会伪装成 00:00 时间点。

索引与搜索说明

内置搜索配置已经包含固定的综合、标题和画面规则。

综合搜索默认按画面 75%、标题 25% 计算，并只对缺失模态的结果做固定降权；这些旧的融合权重不再作为可配置项。需要改变评分、排序或封面可靠性时，请在下面使用自定义预设或 JavaScript 代码。

定时增量索引

新视频在时段外进入等待队列，手动任务立即执行。

每行一个星期，支持周一至周日和 Mon-Sun；同一天多个时段用分号分隔。

搜索结果与搜索配置

搜索页使用文件夹式网格。内置配置在服务端计算；自定义配置把原始候选交给浏览器中的 JavaScript 函数处理。

代码函数签名为 function(items, query, preset, helpers) 的函数体：必须返回数组。每个 item 包含 score、rawVisualScore、visualScore、titleScore、visualSource（trickplay 或 primary_cover）、bestFrame、matchKind 等字段；可修改 item.customScore 后按它排序，也可以按 visualSource 对封面单独处理。JSON 预设的 coverScoreMultiplier 仅作用于封面视觉分，默认 1；例如 0.65 可用于带海报的电影库。可用 helpers.clamp、helpers.scoreText、helpers.timestamp。代码只在当前用户浏览器中运行，不会在 Jellyfin 服务端执行。
